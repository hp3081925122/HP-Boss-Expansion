# HP's Boss Expansion (`hp_boss_expansion`)

合并多个高阶首领（Boss）的多版本 Minecraft 模组项目，当前收录：

- **熔渊巨猩（Cindermaw）**：玄武岩火焰元素首领，围绕活体熔岩炉心与双阶段火焰机制设计。
- **罡风君主（Zephyrarch）**：高阶风暴首领，包含双阶段风暴技能时间轴、罡风核心、暴风徽记与君主裂风刃。

## 多版本分支结构

- `1.21.1-neoforge` — Minecraft 1.21.1 NeoForge（工作树：`1211-neoforge-HPBossExpansion`）
- `26.1.2-neoforge` — Minecraft 26.1.2 NeoForge（工作树：`2612-neoforge-HPBossExpansion`）
- `1.20.1-forge` — Minecraft 1.20.1 Forge（工作树：`1201-forge-HPBossExpansion`）
